STEPS

1. Select line A in another app and press ctrl+option+T: the Panel opens (about 1100×650, centered, floating) with the Input left and the Inspector right; tabs read datetime 1, json 1, url 1, file path 6, Plain Text, each Pattern tab with a color dot matching its tint in the Input.
2. Without Accessibility granted, the footer says the Input is the clipboard; with it, the selection is captured.
3. Hover the datetime: the pointer is the copy cursor (arrow with +); move onto plain text: the I-beam. Click the datetime: "Copied" appears next to the pointer at once.
4. Drag with the real mouse across part of the JSON: that part is selected and nothing is copied.
5. Drag the divider, press Esc, capture again: the size and divider are kept. Quit and relaunch: still kept.
6. Click the tab buttons, then list rows: each selects; the Action bar's first button is emphasized; its buttons work (Open in Browser opens your browser, Open in Editor opens Cursor/your editor).
7. Click rows in a URL's and a datetime's detail: each copies its value; the datetime's "Read as UTC" switch updates every row.
8. On the JSON: the Tree/Text switch works; the node toolbar buttons (Copy Value, Copy Key, Copy Key Path, Expand All, Collapse All) work on the selected node; right-click shows no menu.
9. In Text mode, keys, strings and numbers are colored like VS Code's GitHub theme; click the "url" or a "file" value: it opens. Switch the system appearance: Light/Dark themes swap, and Pattern tints follow their light/dark pair.
10. Capture line D: the {…} badge shows; Parse Inline / Show as String and Open in Window from the node toolbar work.
11. ⌘E toggles the Highlighting toolbar button's state too; ⌘⇧P opens a Match Window that looks like the Inspector's view of that entry (Action bar + detail, no tabs, and no button that opens it again).
12. Set "inspectorLayout": "list" and save, capture line A: no tab bar; one list with sections datetime, json, url, file path, Plain Text, each with its dot and count; click a section's chevron to collapse it; click rows across sections and the detail follows.
13. Click the Tabs/List switch in the toolbar (or press ⌘L): the Inspector flips between tabs and one list; capture again and it stays as you left it.
